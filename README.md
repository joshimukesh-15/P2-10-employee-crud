# Employee CRUD Application

Demonstrates GET, POST, PUT, DELETE, React components, props, state, forms, events, conditional rendering, and list rendering. JSONPlaceholder simulates writes; changes are kept in React state only until refresh.

Project structure:
```text
src/
├── App.jsx
├── main.jsx
├── styles.css
├── components/
└── services/ (where used)
```

Run npm install, then npm run dev in this folder.
